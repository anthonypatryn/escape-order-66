# Escape Order 66

A digital version of the game Escape Order 66: move Ahsoka across a 6 × 6 Galaxy of Clone Wars characters, win the factions'
banners, and hold the most when she runs out of moves. Play another person on one screen, or a computer
(Youngling, Padawan or Jedi Master).

- Play: https://escape-order-66.vercel.app
- Debug lab: `/?view=lab` · bug reports: `/?view=bugs` · card review: `/?view=cards`

```
npm install
npm run dev
node tools/simulate.mjs 200     # headless AI games: must print errors: 0
```
